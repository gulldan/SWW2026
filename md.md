Параметры MD — что пишут в журналах vs что у нас                               
                                                                                                                                                                                                                                                       
  Вот каждый параметр, что он значит простыми словами, что типично для публикаций, и что у нас:                                                                                                                                                        

  1. Софт и силовое поле

  ┌───────────────────────┬─────────────────────────────────────────────────────────────────────────────────────┬─────────────────────────────┬────────────────────────────────────────────────────┐
  │       Параметр        │                              Что это простыми словами                               │    В журналах (типично)     │                       У нас                        │
  ├───────────────────────┼─────────────────────────────────────────────────────────────────────────────────────┼─────────────────────────────┼────────────────────────────────────────────────────┤
  │ MD-движок             │ Программа-симулятор                                                                 │ GROMACS 2020-2024           │ GROMACS 2026.0 ✅ (новее)                          │
  ├───────────────────────┼─────────────────────────────────────────────────────────────────────────────────────┼─────────────────────────────┼────────────────────────────────────────────────────┤
  │ Силовое поле (белок)  │ «Правила физики» для атомов белка — как они притягиваются, отталкиваются, вибрируют │ AMBER ff14SB или CHARMM36   │ amber14sb ✅ (золотой стандарт, Maier et al. 2015) │
  ├───────────────────────┼─────────────────────────────────────────────────────────────────────────────────────┼─────────────────────────────┼────────────────────────────────────────────────────┤
  │ Силовое поле (лиганд) │ То же самое для молекулы-лекарства                                                  │ GAFF/GAFF2 + AM1-BCC заряды │ GAFF2 + AM1-BCC ✅ (через antechamber + acpype)    │
  ├───────────────────────┼─────────────────────────────────────────────────────────────────────────────────────┼─────────────────────────────┼────────────────────────────────────────────────────┤
  │ Модель воды           │ Как симулировать молекулы воды вокруг белка                                         │ TIP3P или SPC/E             │ TIP3P ✅ (стандарт для AMBER)                      │
  └───────────────────────┴─────────────────────────────────────────────────────────────────────────────────────┴─────────────────────────────┴────────────────────────────────────────────────────┘

  Простыми словами: силовое поле — это набор формул и числовых коэффициентов, которые описывают, как каждый атом взаимодействует с каждым. Как «физический движок» в игре, только для молекул. amber14sb — один из самых проверенных и цитируемых.

  ┌──────────────────────┬──────────────────────────────────────────────┬───────────────────────────────┬──────────────────────────────────────────┐
  │       Параметр       │                   Что это                    │          В журналах           │                  У нас                   │
  ├──────────────────────┼──────────────────────────────────────────────┼───────────────────────────────┼──────────────────────────────────────────┤
  │ Форма коробки        │ В какую «коробку» помещается белок с водой   │ Кубическая или додекаэдр      │ Додекаэдр ✅ (экономит ~29% воды vs куб) │
  ├──────────────────────┼──────────────────────────────────────────────┼───────────────────────────────┼──────────────────────────────────────────┤
  │ Расстояние до стенки │ Сколько воды между белком и краем коробки    │ 1.0–1.5 нм                    │ 1.2 нм ✅                                │
  ├──────────────────────┼──────────────────────────────────────────────┼───────────────────────────────┼──────────────────────────────────────────┤
  │ Ионы                 │ Соль вокруг белка (как в крови)              │ 0.15 M NaCl (физиологическая) │ 0.15 M NaCl ✅                           │
  ├──────────────────────┼──────────────────────────────────────────────┼───────────────────────────────┼──────────────────────────────────────────┤
  │ Нейтрализация заряда │ Система должна быть электрически нейтральной │ Да, Na⁺/Cl⁻                   │ Да ✅                                    │
  └──────────────────────┴──────────────────────────────────────────────┴───────────────────────────────┴──────────────────────────────────────────┘

  Простыми словами: белок помещается в «аквариум» с солёной водой, как в организме. Додекаэдр — это как круглый аквариум вместо прямоугольного: меньше лишней воды в углах = быстрее считать.

  4. Уравновешивание (equilibration)

  ┌─────────────────────────┬──────────────────────────────────────────────────────────────────┬───────────────────────┬───────────────────────────────────────────────────────────┐
  │        Параметр         │                             Что это                              │      В журналах       │                           У нас                           │
  ├─────────────────────────┼──────────────────────────────────────────────────────────────────┼───────────────────────┼───────────────────────────────────────────────────────────┤
  │ NVT фаза                │ Прогрев до нужной температуры при постоянном объёме              │ 100 ps, V-rescale     │ 200 ps, V-rescale ✅ (даже дольше)                        │
  ├─────────────────────────┼──────────────────────────────────────────────────────────────────┼───────────────────────┼───────────────────────────────────────────────────────────┤
  │ NPT фаза                │ Стабилизация давления при постоянной температуре                 │ 100 ps, Berendsen     │ 200 ps, C-rescale ✅ (C-rescale новее и точнее Berendsen) │
  ├─────────────────────────┼──────────────────────────────────────────────────────────────────┼───────────────────────┼───────────────────────────────────────────────────────────┤
  │ Температура             │ Целевая температура                                              │ 300 K или 310 K       │ 310 K ✅ (физиологическая, 37°C)                          │
  ├─────────────────────────┼──────────────────────────────────────────────────────────────────┼───────────────────────┼───────────────────────────────────────────────────────────┤
  │ Давление                │ Целевое давление                                                 │ 1 бар                 │ 1 бар ✅                                                  │
  ├─────────────────────────┼──────────────────────────────────────────────────────────────────┼───────────────────────┼───────────────────────────────────────────────────────────┤
  │ Позиционные ограничения │ Белок и лиганд «пришпилены» пружинами пока вода уравновешивается │ Да, 1000 kJ/(mol·nm²) │ Да, белок + лиганд ✅                                     │
  └─────────────────────────┴──────────────────────────────────────────────────────────────────┴───────────────────────┴───────────────────────────────────────────────────────────┘

  Простыми словами:
  - NVT = «нагреваем аквариум» до 37°C. Термостат V-rescale — как хороший кондиционер, держит температуру точно.
  - NPT = «выравниваем давление» — коробка чуть сжимается/расширяется, пока плотность воды не станет правильной.
  - Белок при этом зафиксирован пружинками, чтобы вода уравновешивалась вокруг неподвижного белка.

  5. Продакшен-симуляция (основной прогон)

  ┌─────────────────────────┬─────────────────────────────────────────────────────┬────────────────────────────┬─────────────────────────────────────────────────────────┐
  │        Параметр         │                       Что это                       │         В журналах         │                          У нас                          │
  ├─────────────────────────┼─────────────────────────────────────────────────────┼────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ Длительность            │ Сколько наносекунд симулируем                       │ 10–100 ns (типично 50–100) │ 10 ns ⚠ (минимум, но достаточно для стабильности позы) │
  ├─────────────────────────┼─────────────────────────────────────────────────────┼────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ Шаг интеграции (dt)     │ Через сколько «тиков» пересчитываем позиции атомов  │ 2 fs                       │ 2 fs ✅                                                 │
  ├─────────────────────────┼─────────────────────────────────────────────────────┼────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ Термостат               │ Контроль температуры                                │ V-rescale или Nosé-Hoover  │ V-rescale ✅                                            │
  ├─────────────────────────┼─────────────────────────────────────────────────────┼────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ Баростат                │ Контроль давления                                   │ Parrinello-Rahman          │ Parrinello-Rahman ✅ (gold standard для production)     │
  ├─────────────────────────┼─────────────────────────────────────────────────────┼────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ Кулоновский cutoff      │ На каком расстоянии считаем электростатику напрямую │ 1.0–1.2 нм                 │ 1.0 нм ✅ (AMBER стандарт)                              │
  ├─────────────────────────┼─────────────────────────────────────────────────────┼────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ VdW cutoff              │ На каком расстоянии считаем ван-дер-ваальс          │ 1.0–1.2 нм                 │ 1.0 нм ✅                                               │
  ├─────────────────────────┼─────────────────────────────────────────────────────┼────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ Электростатика          │ Метод дальней электростатики                        │ PME                        │ PME ✅                                                  │
  ├─────────────────────────┼─────────────────────────────────────────────────────┼────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ Constraints             │ Какие связи зафиксированы                           │ h-bonds (LINCS)            │ h-bonds (LINCS) ✅                                      │
  ├─────────────────────────┼─────────────────────────────────────────────────────┼────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ Вывод координат         │ Как часто записываем «кадры»                        │ каждые 10 ps               │ каждые 10 ps ✅                                         │
  ├─────────────────────────┼─────────────────────────────────────────────────────┼────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ Дисперсионная коррекция │ Поправка на обрезанный VdW                          │ EnerPres                   │ EnerPres ✅                                             │
  └─────────────────────────┴─────────────────────────────────────────────────────┴────────────────────────────┴─────────────────────────────────────────────────────────┘

  Простыми словами:
  - dt = 2 fs = каждые 0.000000000000002 секунды пересчитываем позиции всех 728,000 атомов. Это 5 миллионов шагов для 10 ns.
  - Parrinello-Rahman = «умный поршень», который плавно регулирует размер коробки, сохраняя правильное давление. Лучше Berendsen для продакшена.
  - PME = хитрый математический трюк (через Фурье-преобразование) для расчёта электростатики на дальних расстояниях. Без него пришлось бы считать каждую пару атомов = O(N²).
  - LINCS = фиксирует длину связей C-H, N-H и т.д. Эти связи вибрируют так быстро, что иначе пришлось бы делать шаг 1 fs вместо 2 fs.

  7. Общая оценка

  ┌─────────────────────┬──────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │       Аспект        │                                                    Оценка                                                    │
  ├─────────────────────┼──────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ Силовое поле        │ ✅ Топ-уровень (amber14sb + GAFF2)                                                                           │
  ├─────────────────────┼──────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ Подготовка системы  │ ✅ Стандарт (додекаэдр, 0.15M NaCl, 1.2 nm)                                                                  │
  ├─────────────────────┼──────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ Equilibration       │ ✅ Даже лучше типичного (200 ps vs 100 ps, C-rescale vs Berendsen)                                           │
  ├─────────────────────┼──────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ Баростат продакшена │ ✅ Правильный (Parrinello-Rahman)                                                                            │
  ├─────────────────────┼──────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ Анализы             │ ✅ Полный набор + MM-GBSA + convergence test                                                                 │
  ├─────────────────────┼──────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ Длительность        │ ⚠ 10 ns — нижняя граница. Для «стабильна ли поза» достаточно. Для публикации в Nature/JACS обычно 50-100 ns │
  └─────────────────────┴──────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

  Единственная реальная разница — длительность. 10 ns достаточно чтобы показать: «лиганд не улетел из кармана, белок стабилен». Для более глубокого анализа (конформационные переходы, unbinding) нужно 50-100 ns. Но для нашей задачи (валидация позы
  сгенерированной молекулы) 10 ns — это обоснованно.
