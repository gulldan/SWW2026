# Критерии выбора пар белков

## Требования к каждой паре

1. **Доступность структур**: обе мишени должны иметь кристаллические структуры высокого разрешения в PDB (предпочтительно <= 2.5 A).
2. **Понятный сайт связывания**: чётко определённый связывающий карман с известными лигандами (со-кристаллизованными или подтверждёнными в литературе).
3. **Разумный размер**: белок <= 600 остатков (чтобы инференс Boltz-2 был выполним).
4. **Биологическое обоснование**: пара должна иметь обоснование в multi-target дизайне лекарств (селективность, полифармакология или синергия).
5. **Совместимость с Boltz-2**: структуры должны обрабатываться Boltz-2 без кастомных доработок.
6. **Бенчмаркинговый прецедент**: желательно, чтобы пара использовалась в предыдущих dual-target или selectivity исследованиях.

## Выбранные пары

| ID пары     | Мишень A | Мишень B | Обоснование |
|-------------|----------|----------|-------------|
| CDK2_ERK2   | CDK2 (1HCL) | ERK2 (4QTA) | Селективность киназ - обе Ser/Thr киназы со схожими ATP-карманами |
| EGFR_HER2   | EGFR (1M17) | HER2 (3PP0) | Двойное ингибирование EGFR/HER2 для терапии рака |
| COX1_COX2   | COX-1 (1EQG) | COX-2 (3LN1) | Классическая COX-селективность для дизайна НПВС |
| AChE_BChE   | AChE (4EY7) | BChE (4BDS) | Двойное ингибирование холинэстераз для болезни Альцгеймера |

## Почему именно эти пары

- **Киназные пары** (CDK2/ERK2, EGFR/HER2): хорошо изученные связывающие карманы, множество известных ингибиторов, обширные бенчмарки докинга.
- **COX-пара**: золотой стандарт задачи селективности в медицинской химии.
- **Холинэстеразная пара**: multi-target дизайн для нейродегенерации, растущая область исследований.

Все пары имеют:
- PDB-структуры с со-кристаллизованными лигандами
- Обширные данные по активности в ChEMBL
- Управляемые размеры белков (< 600 остатков)
