# Цель проекта

## Гипотеза

RL-генерация молекул, оптимизированная под **двойную целевую функцию** (объединённый скор по мишеням A и B), порождает молекулы с более высоким **dual hit-rate**, чем single-target оптимизация с последующей кросс-оценкой.

## Метод

1. **Генератор**: FREED++ (RL-генерация молекул с docking-скором как наградой).
2. **Скорер**: Boltz-2 (structure-aware скоринг связывания белок-лиганд).
3. **Сравнение**:
   - **Single-target режим**: оптимизация только под мишень A -> скоринг сгенерированных молекул по обеим мишеням A и B.
   - **Double-target режим**: оптимизация под `combined(score_A, score_B)` -> скоринг по обеим мишеням A и B.

## Двойная целевая функция

**Конвенция скоров:** log10(IC50 в μM), меньше = лучше.

### Базовая (baseline)

`combined = max(score_A, score_B)` при *lower-is-better*

Наиболее консервативная функция - молекула оценивается по худшему из двух скоров.
Для минимизации (меньше = лучше) worst-case реализуется через `max(...)`.
Не позволяет оптимизатору "читерить", показывая отличный результат по одной мишени
и игнорируя другую. Используется как baseline для сравнения.

### Альтернативные скаляризации

| Функция | Формула | Свойства |
|---------|---------|----------|
| **Геометрическое среднее** | `sqrt(s_A * s_B)` | Простейшее улучшение над min; балансирует оба скора |
| **Гармоническое среднее** | `2*s_A*s_B / (s_A + s_B)` | Плавно штрафует дисбаланс, мягче min |
| **Взвешенная сумма** | `w*s_A + (1-w)*s_B` | Линейная скаляризация (REINVENT 4, DrugEx v3). Только выпуклый фронт Парето |
| **Взвешенное произведение** | `s_A^w * s_B^(1-w)` | Мягче штрафует дисбаланс, требует положительных скоров |
| **Чебышёв** | `max(w*|s_A - z_A|, (1-w)*|s_B - z_B|)` | Невыпуклые участки фронта Парето (MOEA/D, NSGA-III). z - утопическая точка |

### Продвинутые мульти-объектные подходы

Литература 2024-2026 показывает переход от скаляризации к Парето-методам
как стандарту многоцелевой молекулярной оптимизации.

**Парето-оптимизация:**

- **ParetoDrug** (Communications Biology, 2024) - Pareto MCTS с
  pretrained авторегрессионной моделью. ParetoPUCT балансирует exploration
  и exploitation. GitHub: CNDOTA/ParetoDrug.
- **PMMG** (Advanced Science, 2025) - Pareto MCTS для 7 целей одновременно
  (EGFR/HER2 дуальный дизайн, QED, SA, токсичность). Доля успеха 51.65% -
  в 2.5x выше предыдущих SOTA.
- **CMOMO** (Briefings in Bioinformatics, 2025) - двухэтапный фреймворк
  глубокой многоцелевой оптимизации с динамическими ограничениями.
  2x улучшение доли успеха для ингибиторов GSK3-beta.
- **EHVI** (Expected Hypervolume Improvement) - байесовский поиск на
  фронте Парето. Превосходит скаляризацию по покрытию фронта и
  сходимости при малом бюджете.

**Полифармакологическая генерация:**

- **POLYGON** (Nature Communications, 2024) - VAE + RL для
  полифармакологии. 32 синтезированных соединения на MEK1/mTOR,
  большинство > 50% снижение активности обоих белков.
- **Automated multi-target ligands** (Nature Communications, 2024) -
  химические языковые модели (CLM), pooled fine-tuning. 12 синтезированных
  дизайнов для 6 пар мишеней.

**GFlowNet / Synthesis-aware генерация (2025):**

- **SynFlowNet** (ICLR 2025, Spotlight) - GFlowNet в пространстве
  реальных химических реакций. Генерирует молекулы и пути синтеза.
- **SynGFN** (Nature Computational Science, 2025) - каскад симулированных
  реакций, иерархическая предобученная политика.
- **RxnFlow** (ICLR 2025) - 1.2 млн строительных блоков, 71 шаблон
  реакций. SOTA на CrossDocked2020: средний Vina -8.85 kcal/mol.

**Boltz-2 экосистема (2025):**

- **Boltz-2** (MIT/Recursion, 2025) - предсказание аффинности за 15-30
  секунд вместо часов MD-симуляций. Победитель CASP16 affinity challenge.
  Корреляция Пирсона 0.66, сравнима с лучшими FEP-расчётами.
- **BoltzGen** (bioRxiv, ноябрь 2025) - генеративная модель для дизайна
  нанободов, мини-байндеров и пептидов. Наномолярные хиты для 6/9 мишеней.
- **Boltz-ABFE** (Recursion, 2025) - гибрид: Boltz-2 для скрининга +
  ABFE для физически обоснованной валидации.

**LLM-агенты для молекулярной оптимизации (2025-2026):**

- **MultiMol** (arXiv, 2025) - двойная LLM-система: data-driven агент +
  литературный исследователь. Доля успеха 82.3% vs. 27.5% у предшественников.
- **M4olGen** (arXiv, январь 2026, подано на ICLR 2026) - мультиагентное
  прототипирование + GRPO-оптимизация. SOTA по точному контролю свойств.
- **MCCE** (arXiv, октябрь 2025) - Multi-LLM Collaborative Co-evolution.
  SOTA качество фронта Парето на бенчмарках.

**Multi-objective RL (обновления):**

- **REINVENT 4** (AstraZeneca, 2024+) - 4 генератора, модульный скоринг.
  Активная разработка в 2025-2026. ADMETrix: 27 ADMET + 10 физ-хим свойств.
- **DrugEx v3** - RL + Парето-ранжирование, Tchebycheff стратегии.
- **Mol-AIR** (JCIM, 2025) - адаптивные внутренние награды для RL.

**Клиническая валидация:**

- **Рентосертиб** (Nature Medicine, 2025) - первый AI-препарат в Phase 2a.
  Мишень и молекула найдены генеративным AI (Insilico Medicine).
  От идентификации мишени до кандидата - 18 месяцев.

### Рекомендация по экспериментальному плану

1. **Baseline**: `max(score_A, score_B)` - worst-case скаляризация для lower-is-better
2. **Скаляризации**: geometric, harmonic, weighted_sum, weighted_product,
   tchebycheff - анализ чувствительности к выбору функции
3. **Парето-анализ**: hypervolume contribution + Pareto front coverage -
   пост-анализ и сравнение качества множеств решений
4. **Перспектива**: интеграция PMMG / EHVI / SynFlowNet как полноценной
   Парето-оптимизации (требует доработки reward pipeline)

Подробный обзор литературы: [docs/multi_objective_review.md](multi_objective_review.md)

## Метрики

| Метрика | Определение | Назначение |
|---------|-------------|------------|
| **Dual hit-rate** | Доля молекул с `score_A <= T_A` И `score_B <= T_B` | Основной результат |
| Hit-rate A | Доля с `score_A <= T_A` | Результат по мишени |
| Hit-rate B | Доля с `score_B <= T_B` | Результат по мишени |
| Enrichment@K | `(hits_in_top_K / K) / (total_hits / N)` | Качество ранжирования |
| KS-тест | Статистика Колмогорова-Смирнова (single vs double) | Различие распределений |
| Mann-Whitney U | + rank-biserial r | Размер эффекта |

## Выходные артефакты пайплайна

После полного прогона пайплайн формирует следующие артефакты анализа:

| Артефакт | Путь | Описание |
|----------|------|----------|
| Агрегированные данные | `report/data/all_results.parquet` | Все молекулы со скорами, объединённые по парам и режимам |
| Графики распределений | `report/figures/{pair}_*.png` | Гистограммы, ECDF, боксплоты single vs double |
| Рендер молекул | `report/figures/{pair}_molecules_*.png` | 2D-структуры с аннотациями скоров и маркировкой хитов |
| Метрики хитов | `report/metrics.json` | Hit-rate (single, dual) по каждой паре и режиму |
| Стат. тесты | `report/stats.json` | KS-тест, Mann-Whitney U, rank-biserial r |
| Текстовый отчёт | `report/summary.txt` | Сводная аналитика: распределения, хиты, вердикты |

Рендер молекул (`render_molecules.py`) использует matplotlib для читаемых аннотаций
и цветовой маркировки хитов (зелёная рамка для молекул с обоими скорами ниже порога).
Текстовый отчёт (`summarize.py`) — финальный итог пайплайна с медианами, IQR,
статистическими вердиктами и топ-молекулами.

## Критерии успеха

Double-target режим считается **успешным**, если:
1. Dual hit-rate (double) > dual hit-rate (single) для >= 3 из 4 пар.
2. Различие статистически значимо (Mann-Whitney p < 0.05).
3. Нет катастрофической деградации single-target hit-rates (падение < 20%).
