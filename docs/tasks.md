 Metric Definitions

 - Data source: scored_joined.csv per seed (unique molecules only)                                                                                                                                                                                     
 - Hierarchical bootstrap: resample 5 seeds → resample molecules within each seed → compute HR                                                                                                                                                         
                                                                                                                                                                                                                                                       
 balance (H2a, H2b):                                                                                                                                                                                                                                   
 - Per molecule: |affinity_a - affinity_b| (RAW affinities, not z-normalized)                                                                                                                                                                          
 - Per seed: median over unique molecules                                                                                                                                                                                                              
 - Data source: scored_joined.csv (after deduplication within seed)                                                                                                                                                                                    
 - Hierarchical bootstrap: resample seeds → resample molecules → compute median

 Task 2.1: Statistical Module

 Implement:                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                       
 1. hierarchical_bootstrap_test(scored_csvs_a, scored_csvs_b, metric_fn, n_bootstrap=10000, rng_seed=42)                                                                                                                                               
   - Input: 2 lists of 5 paths to scored_joined.csv (one per seed)                                                                                                                                                                                     
   - metric_fn: function computing statistic (e.g., hr_both or balance)                                                                                                                                                                                
   - Process:                                                                                                                                                                                                                                          
 a. ONCE: Load all 10 CSVs into memory (5 per group), cache DataFrames                                                                                                                                                                                 
 b. For each bootstrap iteration (with fixed RNG seed=42):                                                                                                                                                                                             
       - Resample 5 seed indices with replacement from [0, 1, 2, 3, 4]                                                                                                                                                                                 
     - For each resampled seed: resample molecule indices from cached DataFrame, compute metric                                                                                                                                                        
     - Aggregate across seeds (mean)                                                                                                                                                                                                                   
 c. Compare observed difference to bootstrap distribution                                                                                                                                                                                              
   - Return: {mean_diff, p_value, ci_lower, ci_upper}                                                                                                                                                                                                  
   - Note: CSV loading once prevents I/O overhead and ensures stability                                                                                                                                                                                
 2. fdr_correction(p_values, alpha=0.05)                                                                                                                                                                                                               
   - Benjamini-Hochberg procedure                                                                                                                                                                                                                      
   - Unit test: compare [0.01, 0.04, 0.03, 0.05] against known BH output from R or statsmodels                                                                                                                                                         
 3. cliffs_delta(group_a, group_b)                                                                                                                                                                                                                     
   - Non-parametric effect size (PRIMARY)                                                                                                                                                                                                              
   - Interpretation: |delta| >= 0.33 = medium                                                                                                                                                                                                          
 4. cohens_d(group_a, group_b)                                                                                                                                                                                                                         
   - Cohen's d (SUPPLEMENTAL, for reporting only)                                                                                                                                                                                                      
 5. bootstrap_ci(data, statistic_fn, n_bootstrap=10000, rng_seed=42)                                                                                                                                                                                   
   - Percentile method                                                                                                                                                                                                                                 
   - Fixed RNG seed for reproducibility
