Methodology: Binding Site Similarity Assessment

Data Type. The “Binding Site Similarity” column is a literature-curated assessment, not a de novo computational analysis. All values are aggregated from published peer-reviewed sources (see hyperlinked PMC/DOI references in each row).

Similarity Metrics. Because the 50 pairs span diverse protein families, no single universal metric applies. The metric used for each pair reflects the standard adopted in its respective field:

  • Kinase pairs — kinase domain or ATP-binding site sequence identity (% from published alignments or UniProt data)
  • Nuclear receptor pairs — ligand-binding domain (LBD) sequence identity (%)
  • Enzyme pairs (non-kinase) — catalytic domain or active-site residue conservation (%)
  • Cross-family pairs (different folds) — qualitative assessment (“None”) with explanation of the combination rationale

Selectivity Ratio. Derived from IC50, Ki, Kd, or EC50 values of known dual-target or multi-target inhibitors, as reported in the cited publications. Values are from cell-free biochemical assays unless noted otherwise. IC50 values vary across assay conditions; the ratios are most meaningful as relative measures within a single study, not as absolute numbers.

Classification Scale. The 7-level color scale (Very High >80%, High 60–80%, Mod-High 50–60%, Moderate 30–50%, Low 15–30%, Very Low <15%, None) maps heterogeneous metrics to a unified ordinal scale for comparative pair selection. Threshold boundaries are approximate and intended for ranking, not quantitative inference.

  4. For structural validation: superpose PDB structures and compute binding-site RMSD + Tanimoto coefficient for residue composition
