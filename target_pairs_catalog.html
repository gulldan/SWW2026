Methodology

Binding Site Similarity. Literature-curated from peer-reviewed alignments. Kinase pairs: kinase domain or ATP-site seq ID. NR pairs: LBD seq ID. Enzymes: catalytic domain conservation.

NW Alignment. Full-sequence and domain-specific Needleman-Wunsch (BLOSUM62, gap −10/−0.5). Domain ranges from UniProt/InterPro. Verified via verify_pair.py --full.

ChEMBL Bioactivity. IC50, Ki, Kd counts from ChEMBL v34 REST API. Total includes all standard activity types.

Structure Quality. All PDB entries: human, resolution ≤2.5Å, co-crystallized ligand. Verified via RCSB REST API.
