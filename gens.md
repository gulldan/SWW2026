  Что из этого наиболее релевантно для DualDock как альтернатива/comparison FREED++:

  1. REINVENT 4 — промышленный стандарт, SMILES-based RL, уже поддерживает multi-component scoring. Проще всего интегрировать.
  2. MDRL (2025) — 3D diffusion + RL для multi-target. Прямой конкурент, самый свежий.
  3. AIxFuse (2024) — dual-pocket structure-aware RL. Ближайший по задаче.
  4. DiffDTM — diffusion с dual-sequence conditioning. Не требует 3D структур.
  5. MTMol-GPT — GPT для multi-target, ligand-based.
  6. PMMG — MCTS для Pareto front с docking, тестировался на EGFR/HER2.

  По презентации: ранние эксперименты на опиоидных рецепторах (kappa/mu/nociceptin) с selective docking — это ценный preliminary data. Результаты показывают dataset bias (больше лигандов для mu), что стоит обсудить в статье.
